Korean-Lao Translator V3.60 / Relay v3.7.0
Final test notes

[핵심 변경]
1. 번역 품질점수는 참고용 표시/기록으로만 사용. 점수 자체로 자동 재번역/Hedge/Rescue/결과교체를 하지 않음.
2. 재번역 버튼은 번역 완료 후 점수와 무관하게 항상 사용 가능.
3. Critical Meaning 자동복구는 1단계. 첫 복구 요청이 느릴 때만 같은 단계의 Hedge 허용.
4. HARD_CORRUPTION은 1회 자동 재시도 후 경고. 복사/TTS/재번역 잠금 없음.
5. 남편/아내 모두 복사 결과 = 번역본 1줄 + 엄격 직역 역번역 1줄.
6. 역번역은 원문 복원/의역 금지, 실제 번역문 직역 검증용.
7. STT 정상 WebSocket 경로 유지. 실패 시 반대 지역 REST STT 1회 → 같은 WAV로 AI 음성전사 1회 → 재녹음 안내.
8. STT REST client 10s / provider 8.5s, AI fallback client 12s / provider 10.5s.
9. Firestore 실사용 번역 전체 저장. 부모 실사용 기록 최대 약 20,000건 롤링, 오래된 부모부터 삭제.
10. 재검사 결과는 부모 번역 기록 아래 replays 이력으로 저장. 사람 판정/메모 저장 지원.
11. 완전 실패 번역도 source/failure/runtime 정보로 저장 가능.
12. 로컬 미전송 telemetry queue 최대 100개, 번역 경로를 막지 않고 idle 전송.
13. 자동업데이트는 상태 기반. 입력 dirty/번역/역번역/STT/TTS/복사 등 실제 작업 중에는 적용 보류.
14. 앱 내 음성입력 안내 및 최종 한국어/라오어 사용설명서 동기화.
