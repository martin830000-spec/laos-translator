한-라오 번역기 V3.60 상세 사용설명서
Korean–Lao Translator V3.60 User Guide

============================================================
[한국어 사용설명서]
============================================================

1. 앱의 용도
- 이 앱은 한국인 남편과 라오스인 아내가 실제 일상대화를 번역하기 위한 앱입니다.
- 남편 모드: 한국어 → 라오어
- 아내 모드: 라오어 → 한국어
- 번역은 원문의 말투와 의미를 최대한 유지하도록 설계되어 있습니다.

2. 빠른 시작
① 앱을 실행합니다.
② 남편용 또는 아내용 모드를 선택합니다.
③ 입력창에 문장을 입력합니다.
④ [번역하기] 버튼을 누릅니다.
⑤ 번역본과 역번역을 함께 확인합니다.
⑥ 메신저에 보낼 때 [번역본 복사] 또는 [복사] 버튼을 누릅니다.

3. 텍스트 입력
- 남편앱: 한국어를 입력합니다.
- 아내앱: 라오어를 입력합니다.
- 최대 입력 길이는 화면의 글자 수 표시를 참고하세요.
- PC에서는 남편앱에서 Ctrl+Enter를 이용해 빠르게 번역할 수 있습니다.

4. 앱 안의 음성입력 사용법 — 중요
앱 자체의 🎙️ 음성입력 버튼은 휴대폰 키보드의 마이크와 별개의 기능입니다.

정확한 순서:
① 🎙️ [음성입력] 버튼을 한 번 누릅니다. → 녹음 시작
② 말합니다.
③ 같은 🎙️ 버튼을 다시 한 번 누릅니다. → 녹음 종료
④ 인식된 문장이 입력창에 나타나는지 확인합니다.
⑤ 문장이 맞으면 [번역하기] 버튼을 누릅니다.

주의:
- 음성입력 버튼을 한 번만 누른 뒤 계속 기다리는 방식이 아닙니다.
- 말이 끝난 뒤 같은 버튼을 다시 눌러 녹음을 종료해야 합니다.
- 음성인식이 끝나도 자동으로 번역하지 않습니다. 인식 문장을 먼저 확인한 뒤 번역 버튼을 누르세요.

5. 휴대폰 키보드의 음성입력
- 키보드 마이크는 휴대폰/키보드 앱이 제공하는 기능이며 앱 내부 음성입력과 다릅니다.
- 지원 언어는 휴대폰, 운영체제, 키보드 설정에 따라 달라질 수 있습니다.
- 특히 iPhone에서 라오어 키보드 음성입력이 지원되지 않거나 원하는 언어로 인식되지 않으면 앱 안의 🎙️ 음성입력을 사용하세요.

6. 음성인식이 잘 안 될 때
앱은 정상 음성인식이 실패했을 때 내부적으로 복구를 시도할 수 있습니다. 이 경우 평소보다 결과가 늦게 나타날 수 있습니다.
- 조용한 곳에서 다시 말해보세요.
- 문장을 너무 멀리서 말하지 마세요.
- 음성인식이 끝까지 실패하면 다시 말해달라는 안내가 표시될 수 있습니다.
- 연결 지연 안내가 나왔다고 반드시 휴대폰 인터넷 전체에 문제가 있다는 뜻은 아닙니다. 잠시 후 다시 시도해보세요.

7. 번역 결과 확인
- 주 번역 결과가 먼저 표시됩니다.
- 번역점수는 참고용입니다.
- 점수가 낮아도 복사, 듣기, 재번역 기능을 제한하지 않습니다.
- 점수만을 이유로 앱이 문장을 마음대로 고치지는 않습니다.
- 번역이 어색하다고 느끼면 사용자가 직접 [다시 시도]/[재번역]을 누르세요.

8. 의미 확인 경고
- 화자, 부정/긍정, 허용/금지, 숫자, 시간, 이동방향 등 중요한 의미가 뒤집힐 가능성이 감지되면 앱이 한 번 안전 복구를 시도할 수 있습니다.
- 그래도 확인이 필요한 경우 경고를 보여줍니다.
- 경고가 있어도 사용자가 복사, 듣기, 재번역을 직접 선택할 수 있습니다.
- 최종 판단은 번역본과 역번역을 읽고 사람이 직접 하는 것이 가장 안전합니다.

9. 문자 깨짐 경고
- 결과에 � 같은 깨진 문자가 감지되면 앱이 자동으로 한 번 다시 시도할 수 있습니다.
- 다시 시도한 뒤에도 문제가 남으면 경고가 표시됩니다.
- 경고가 표시되어도 결과 확인, 복사, 듣기, 재번역은 사용할 수 있습니다.

10. 역번역의 의미
- 역번역은 번역본이 제대로 전달되는지 확인하기 위한 크로스체크 기능입니다.
- 역번역은 원문을 예쁘게 다시 만드는 것이 아니라 실제 번역 결과를 최대한 직역해서 되돌려 보여주는 용도입니다.
- 번역본과 역번역의 의미가 크게 다르면 메신저로 보내기 전에 재번역하거나 문장을 직접 고치는 것을 권장합니다.

11. 메신저로 복사하기
남편앱과 아내앱 모두 같은 방식입니다.

복사 결과:
1번째 줄: 번역본
2번째 줄: 역번역

- 두 줄 사이에 빈 줄을 넣지 않습니다.
- '한국어', '라오어', '역번역' 같은 라벨을 붙이지 않습니다.
- 역번역이 아직 만들어지는 중이면 복사할 때 잠시 기다릴 수 있습니다.
- 역번역이 최종적으로 준비되지 않으면 원문을 역번역처럼 대신 넣지 않습니다. 다시 확인한 뒤 복사하라는 안내가 표시됩니다.

12. 음성으로 번역 결과 듣기
- 음성출력이 켜져 있으면 번역 결과를 들을 수 있습니다.
- 재생 중 같은 듣기/중지 버튼을 누르면 음성을 멈출 수 있습니다.
- 음성 재생 중에는 앱 업데이트가 갑자기 적용되지 않도록 대기합니다.

13. 최근 번역과 즐겨찾기
- 최근 번역은 현재 기기에 최대 50개까지 보관됩니다.
- 화면에는 최근 항목 최대 10개를 표시합니다.
- 필요한 문장은 즐겨찾기로 표시하거나 다시 불러올 수 있습니다.
- [기록 삭제]를 누르면 사용자가 직접 최근 기록을 삭제할 수 있습니다.

14. 자동업데이트
- 새 버전이 있으면 앱은 자동업데이트를 사용할 수 있습니다.
- 다음 작업 중에는 업데이트를 강제로 적용하지 않습니다.
  · 입력 중인 문장이 아직 번역되지 않은 상태
  · 번역 중
  · 역번역 중
  · 음성입력/음성인식 중
  · 음성 재생 또는 준비 중
  · 재번역 중
  · 복사 처리 중
- 작업이 모두 끝나 안전한 상태가 되면 업데이트를 적용합니다.
- 최근 번역, 현재 모드, 사용자 설정 및 아직 전송되지 않은 내부 기록은 가능한 한 유지됩니다.

15. Android 사용 시
- Chrome 계열 브라우저에서 앱을 사용합니다.
- 마이크 권한 요청이 나오면 앱 음성입력을 사용하려는 경우 허용합니다.
- 화면 키보드가 올라왔을 때 입력창이 가려지는 경우 키보드를 닫았다가 다시 입력창을 눌러보세요.
- Galaxy Z Fold 계열은 외부화면에서도 사용할 수 있도록 화면 크기에 맞게 구성되어 있습니다.

16. iPhone 사용 시
- Safari에서 사용할 수 있습니다.
- 처음 음성입력을 사용할 때 마이크 권한을 확인하세요.
- iPhone 키보드의 음성입력 언어와 앱 내부 음성입력 언어는 별개입니다.
- 라오어 키보드 음성입력이 지원되지 않거나 한국어 등 다른 언어로 입력된다면 앱 내부 🎙️ 버튼을 사용하세요.
- 앱 내부 음성입력은 반드시 시작할 때 한 번, 말이 끝난 뒤 다시 한 번 눌러 종료합니다.

17. PC 사용 시
- 키보드로 문장을 입력한 뒤 번역 버튼을 사용할 수 있습니다.
- 남편앱에서는 Ctrl+Enter로 빠르게 번역할 수 있습니다.
- PC의 시스템 음성입력 기능은 운영체제 설정에 따라 별도로 동작합니다.

18. 문제가 있을 때 먼저 확인할 것
번역이 안 됨:
- 입력문이 비어 있지 않은지 확인
- 잠시 후 다시 시도
- 계속 실패하면 앱을 다시 열어 확인

음성입력이 안 됨:
- 마이크 권한 확인
- 🎙️ 버튼을 눌러 시작했는지 확인
- 말한 뒤 같은 버튼을 다시 눌러 종료했는지 확인
- 그래도 안 되면 다시 말하기

번역이 이상함:
- 역번역을 먼저 확인
- 번역점수는 참고만 하고 실제 문장의 의미를 직접 판단
- 필요하면 [재번역]을 누르거나 원문을 더 명확하게 고쳐 다시 번역

19. 가장 중요한 사용 원칙
- 번역점수는 참고용입니다.
- 역번역은 크로스체크용입니다.
- 중요한 내용은 번역본과 역번역을 사람이 직접 읽고 확인하세요.
- 앱의 자동 안전검사는 도움을 주는 기능이지 사용자의 최종 판단을 대신하지 않습니다.

[ຄູ່ມືການໃຊ້ງານພາສາລາວ]

1. ຈຸດປະສົງຂອງແອັບ
- ແອັບນີ້ສ້າງຂຶ້ນເພື່ອໃຫ້ຜົວຊາວເກົາຫຼີ ແລະ ພັນລະຍາຊາວລາວໃຊ້ແປບົດສົນທະນາປະຈຳວັນ.
- ໂໝດຜົວ: ພາສາເກົາຫຼີ → ພາສາລາວ
- ໂໝດພັນລະຍາ: ພາສາລາວ → ພາສາເກົາຫຼີ
- ແອັບພະຍາຍາມຮັກສາຄວາມໝາຍ ແລະ ລະດັບຄຳເວົ້າຂອງຕົ້ນສະບັບ.

2. ເລີ່ມໃຊ້ຢ່າງໄວ
① ເປີດແອັບ.
② ເລືອກໂໝດຜົວ ຫຼື ໂໝດພັນລະຍາ.
③ ພິມຂໍ້ຄວາມໃສ່ຊ່ອງພິມ.
④ ກົດປຸ່ມ [ແປ].
⑤ ກວດທັງຜົນແປ ແລະ ຄຳແປກັບເພື່ອກວດຄວາມໝາຍ.
⑥ ເມື່ອຈະສົ່ງໃນແຊັດ ໃຫ້ກົດປຸ່ມຄັດລອກ.

3. ການພິມຂໍ້ຄວາມ
- ໂໝດຜົວໃສ່ພາສາເກົາຫຼີ.
- ໂໝດພັນລະຍາໃສ່ພາສາລາວ.
- ກວດຈຳນວນຕົວອັກສອນຈາກຕົວເລກໃຕ້ຊ່ອງພິມ.

4. ວິທີໃຊ້ປຸ່ມ 🎙️ ຮັບສຽງໃນແອັບ — ສຳຄັນ
ປຸ່ມຮັບສຽງຂອງແອັບ ແລະ ໄມໂຄຣໂຟນຂອງແປ້ນພິມໂທລະສັບແມ່ນຄົນລະຟັງຊັນ.

ລຳດັບທີ່ຖືກຕ້ອງ:
① ກົດ 🎙️ [ຮັບສຽງ] 1 ຄັ້ງ → ເລີ່ມບັນທຶກສຽງ
② ເວົ້າ.
③ ກົດປຸ່ມ 🎙️ ອັນເດີມອີກ 1 ຄັ້ງ → ຢຸດບັນທຶກ
④ ກວດວ່າຂໍ້ຄວາມທີ່ແອັບຟັງໄດ້ປາກົດໃນຊ່ອງພິມຫຼືບໍ່.
⑤ ຖ້າຂໍ້ຄວາມຖືກ ໃຫ້ກົດປຸ່ມ [ແປ].

ຂໍ້ຄວນຮູ້:
- ບໍ່ແມ່ນກົດປຸ່ມຄັ້ງດຽວແລ້ວລໍຖ້າຕະຫຼອດ.
- ຫຼັງຈາກເວົ້າຈົບ ຕ້ອງກົດປຸ່ມອີກຄັ້ງເພື່ອຢຸດ.
- ຫຼັງຈາກຮັບສຽງສຳເລັດ ແອັບຈະບໍ່ແປອັດຕະໂນມັດ. ໃຫ້ອ່ານຂໍ້ຄວາມກ່ອນແລ້ວຈຶ່ງກົດແປ.

5. ໄມໂຄຣໂຟນຂອງແປ້ນພິມໂທລະສັບ
- ເປັນຟັງຊັນຂອງໂທລະສັບ/ແປ້ນພິມ ບໍ່ແມ່ນຟັງຊັນຮັບສຽງຂອງແອັບ.
- ພາສາທີ່ຮອງຮັບອາດຕ່າງກັນຕາມໂທລະສັບ, ລະບົບ ແລະ ການຕັ້ງຄ່າແປ້ນພິມ.
- ຖ້າ iPhone ບໍ່ຮອງຮັບການພິມດ້ວຍສຽງພາສາລາວ ຫຼື ຮັບສຽງເປັນພາສາອື່ນ ໃຫ້ໃຊ້ປຸ່ມ 🎙️ ໃນແອັບ.

6. ເມື່ອຮັບສຽງບໍ່ສຳເລັດ
- ແອັບອາດລອງກູ້ຄືນການຮັບສຽງພາຍໃນ. ຕອນນີ້ອາດໃຊ້ເວລາດົນກວ່າປົກກະຕິ.
- ລອງເວົ້າໃໝ່ໃນບ່ອນທີ່ສຽງລົບກວນນ້ອຍ.
- ຢ່າໃຫ້ໂທລະສັບຢູ່ໄກເກີນໄປ.
- ຖ້າຍັງຟັງບໍ່ໄດ້ ແອັບຈະແນະນຳໃຫ້ເວົ້າໃໝ່.
- ຂໍ້ຄວາມວ່າການຮັບສຽງຊ້າ ບໍ່ໄດ້ໝາຍຄວາມວ່າອິນເຕີເນັດຂອງໂທລະສັບເສຍທັງໝົດ. ລອງໃໝ່ອີກຄັ້ງ.

7. ການກວດຜົນແປ
- ຜົນແປຫຼັກຈະສະແດງກ່ອນ.
- ຄະແນນຄຸນນະພາບເປັນຂໍ້ມູນອ້າງອີງເທົ່ານັ້ນ.
- ຄະແນນຕ່ຳບໍ່ໄດ້ປິດການຄັດລອກ, ຟັງສຽງ ຫຼື ແປໃໝ່.
- ແອັບຈະບໍ່ປ່ຽນປະໂຫຍກເອງພຽງເພາະຄະແນນຕ່ຳ.
- ຖ້າຮູ້ສຶກວ່າຜົນແປແປກ ໃຫ້ກົດ [ລອງໃໝ່]/[ແປໃໝ່].

8. ຄຳເຕືອນຄວາມໝາຍສຳຄັນ
- ຖ້າພົບຄວາມສ່ຽງເຊັ່ນ ຜູ້ເວົ້າສະຫຼັບ, ປະຕິເສດ/ຢືນຢັນສະຫຼັບ, ອະນຸຍາດ/ຫ້າມ, ຕົວເລກ, ເວລາ, ທິດທາງການເດີນທາງ ແອັບອາດລອງກູ້ຄືນ 1 ຄັ້ງ.
- ຖ້າຍັງຄວນກວດ ແອັບຈະສະແດງຄຳເຕືອນ.
- ແມ່ນແຕ່ມີຄຳເຕືອນ ຜູ້ໃຊ້ຍັງສາມາດຄັດລອກ, ຟັງ ແລະ ແປໃໝ່ໄດ້.

9. ຕົວອັກສອນເສຍ
- ຖ້າພົບຕົວອັກສອນ � ຫຼື ຕົວອັກສອນເສຍ ແອັບອາດລອງແປໃໝ່ອັດຕະໂນມັດ 1 ຄັ້ງ.
- ຖ້າຍັງມີບັນຫາ ຈະມີຄຳເຕືອນ ແຕ່ຍັງສາມາດກວດ, ຄັດລອກ, ຟັງ ແລະ ແປໃໝ່ໄດ້.

10. ການແປກັບເພື່ອກວດຄວາມໝາຍ
- ມີໄວ້ເພື່ອເຊັກວ່າຜົນແປຫຼັກສື່ຄວາມໝາຍຖືກຫຼືບໍ່.
- ການແປກັບຈະພະຍາຍາມແປຕາມຜົນແປທີ່ເກີດຂຶ້ນຈິງແບບກົງ ບໍ່ແມ່ນການເດົາຕົ້ນສະບັບໃຫ້ສວຍງາມ.
- ຖ້າຄວາມໝາຍຂອງຜົນແປ ແລະ ການແປກັບຕ່າງກັນຫຼາຍ ໃຫ້ແປໃໝ່ ຫຼື ແກ້ຕົ້ນສະບັບກ່ອນສົ່ງ.

11. ການຄັດລອກໄປແຊັດ
ໂໝດຜົວ ແລະ ໂໝດພັນລະຍາໃຊ້ຮູບແບບດຽວກັນ:
ແຖວທີ 1: ຜົນແປ
ແຖວທີ 2: ການແປກັບ

- ບໍ່ມີແຖວຫວ່າງລະຫວ່າງສອງແຖວ.
- ບໍ່ໃສ່ປ້າຍຊື່ພາສາ ຫຼື ຄຳວ່າ “ການແປກັບ”.
- ຖ້າການແປກັບຍັງກຳລັງເຮັດ ເວລາກົດຄັດລອກອາດລໍຖ້າສັກຄູ່.
- ຖ້າການແປກັບບໍ່ສຳເລັດ ແອັບຈະບໍ່ນຳຕົ້ນສະບັບມາແທນ. ໃຫ້ກວດແລ້ວຄັດລອກໃໝ່.

12. ການຟັງສຽງຜົນແປ
- ເມື່ອເປີດສຽງ ສາມາດຟັງຜົນແປໄດ້.
- ລະຫວ່າງຫຼິ້ນສຽງ ສາມາດກົດປຸ່ມອີກຄັ້ງເພື່ອຢຸດ.
- ລະຫວ່າງກຳລັງຫຼິ້ນສຽງ ແອັບຈະລໍຖ້າກ່ອນນຳໃຊ້ອັບເດດ.

13. ປະຫວັດການແປ ແລະ ລາຍການມັກ
- ປະຫວັດການແປໃນເຄື່ອງເກັບໄດ້ສູງສຸດ 50 ລາຍການ.
- ໜ້າຈໍສະແດງສູງສຸດ 10 ລາຍການຫຼ້າສຸດ.
- ສາມາດເຮັດເປັນລາຍການມັກ ຫຼື ນຳຂໍ້ຄວາມກັບມາໃຊ້ອີກ.
- ປຸ່ມລຶບປະຫວັດແມ່ນການລຶບໂດຍຜູ້ໃຊ້ເອງ.

14. ອັບເດດອັດຕະໂນມັດ
- ແອັບສາມາດອັບເດດອັດຕະໂນມັດເມື່ອມີລຸ້ນໃໝ່.
- ຈະບໍ່ບັງຄັບອັບເດດລະຫວ່າງ:
  · ກຳລັງແກ້/ພິມຂໍ້ຄວາມທີ່ຍັງບໍ່ໄດ້ແປ
  · ກຳລັງແປ
  · ກຳລັງແປກັບ
  · ກຳລັງຮັບສຽງ
  · ກຳລັງກຽມ/ຫຼິ້ນສຽງ
  · ກຳລັງແປໃໝ່
  · ກຳລັງຄັດລອກ
- ເມື່ອທຸກຢ່າງຢູ່ໃນສະຖານະປອດໄພ ຈຶ່ງນຳໃຊ້ອັບເດດ.

15. Android
- ໃຊ້ຜ່ານບຣາວເຊີທີ່ຮອງຮັບ.
- ຖ້າຈະໃຊ້ຮັບສຽງ ໃຫ້ອະນຸຍາດໄມໂຄຣໂຟນເມື່ອລະບົບຖາມ.
- ຖ້າແປ້ນພິມບັງຊ່ອງພິມ ໃຫ້ປິດແປ້ນພິມແລ້ວແຕະຊ່ອງພິມໃໝ່.

16. iPhone
- ສາມາດໃຊ້ໃນ Safari.
- ກວດກາສິດໄມໂຄຣໂຟນເມື່ອໃຊ້ຮັບສຽງຄັ້ງທຳອິດ.
- ການພິມດ້ວຍສຽງຂອງແປ້ນພິມ iPhone ແລະ ການຮັບສຽງໃນແອັບເປັນຄົນລະຟັງຊັນ.
- ຖ້າແປ້ນພິມບໍ່ຮອງຮັບພາສາລາວ ໃຫ້ໃຊ້ 🎙️ ໃນແອັບ.
- ຈື່ໄວ້: ກົດເລີ່ມ 1 ຄັ້ງ → ເວົ້າ → ກົດອີກ 1 ຄັ້ງເພື່ອຢຸດ.

17. PC
- ພິມຂໍ້ຄວາມແລ້ວກົດປຸ່ມແປ.
- ໃນໂໝດຜົວ ສາມາດໃຊ້ Ctrl+Enter ເພື່ອແປໄວ.
- ຟັງຊັນຮັບສຽງຂອງລະບົບ PC ຂຶ້ນກັບການຕັ້ງຄ່າຂອງເຄື່ອງ.

18. ເມື່ອມີບັນຫາ
ແປບໍ່ໄດ້:
- ກວດວ່າຊ່ອງພິມບໍ່ວ່າງ.
- ລໍຖ້າສັກຄູ່ແລ້ວລອງໃໝ່.
- ຖ້າຍັງບໍ່ໄດ້ ປິດແລ້ວເປີດແອັບໃໝ່.

ຮັບສຽງບໍ່ໄດ້:
- ກວດສິດໄມໂຄຣໂຟນ.
- ກວດວ່າໄດ້ກົດ 🎙️ ເພື່ອເລີ່ມ.
- ຫຼັງເວົ້າຈົບ ກວດວ່າໄດ້ກົດປຸ່ມອີກຄັ້ງເພື່ອຢຸດ.
- ຖ້າຍັງບໍ່ໄດ້ ໃຫ້ເວົ້າໃໝ່.

ຜົນແປແປກ:
- ກວດການແປກັບກ່ອນ.
- ຄະແນນເປັນພຽງຂໍ້ມູນອ້າງອີງ.
- ຖ້າຈຳເປັນ ໃຫ້ແປໃໝ່ ຫຼື ແກ້ຕົ້ນສະບັບໃຫ້ຊັດເຈນກວ່າເກົ່າ.

19. ຫຼັກສຳຄັນ
- ຄະແນນການແປແມ່ນຂໍ້ມູນອ້າງອີງ.
- ການແປກັບແມ່ນສຳລັບກວດຄວາມໝາຍ.
- ຂໍ້ຄວາມສຳຄັນຄວນອ່ານທັງຜົນແປ ແລະ ການແປກັບດ້ວຍຕົນເອງ.
- ການກວດອັດຕະໂນມັດເປັນຕົວຊ່ວຍ ບໍ່ແມ່ນຕົວແທນການຕັດສິນຂອງຄົນ.
