24문장 TXT 미선택


입력 문장 수 자동 계산 · 전량 검사


품질 비교 주의: 같은 원문을 모든 선택 엔진에 전달합니다. Gemini는 기존 중립 지시문, Claude는 엔진별 부부 역할·말투 경량 지시문을 사용하므로 모델 단독 성능이 아닌 모델+프롬프트 조합 비교입니다. Sonnet 5.5 S1 전용 프롬프트를 추가했습니다. Sonnet 기존 R1·Haiku LOW R3·Gemini 중립 프롬프트는 보존됩니다. 각 엔진의 프롬프트는 다르므로 이는 모델+프롬프트 비교이고 SERVICE P168A R8과 다릅니다. 정번역 1회·실제 결과 기반 독립 역번역 1회를 실행하며, SERVICE P168A R8과는 다른 TEST입니다.
역번역은 해당 엔진의 정번역 결과만 새 요청으로 다시 번역합니다. 원문과 별도의 '정답'을 주지 않으며, 역번역 일치율만으로 정번역 품질을 평가하지 않습니다.








호출 예정 수 = 아직 검사하지 않은 (문장 × 엔진 × 회차) × 정·독립역 최대 2회. 입력한 문장 모두 지원하며, 기존 결과 파일을 읽으면 완료·실패 기록은 중복 호출하지 않습니다. 개별 모델 실패는 기록하고 다음 모델로 진행합니다. API 과금과 공급자 자체 한도는 적용되며, 자동 재시도는 없습니다. 검사 도중에도 TXT/JSON 결과를 저장할 수 있습니다.
