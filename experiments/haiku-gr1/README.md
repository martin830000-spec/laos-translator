# GR1: grammatical interpretation options, offline TEST

The empirical motivation is unresolved app92/app67 plus the new normal8 run:
correct source copying and dictionary boundaries still permit relation errors.
This candidate supplies two narrowly sourced grammar cards and verbatim marker
offsets. It does not select an actor, condition attachment or translated answer.
It is prompt conditioning with a language reference, **not** a semantic parser
or a demonstrated new model capability. A source matching the marker can also
use it literally: false-positive bias is a material risk to test.

There are no bilingual training examples, phone-specific rules, date answers,
fact summaries, second candidates, rewrites, extra model calls or unit-order
changes. Korean inputs and unmatched Lao inputs equal frozen LA1 exactly.
Current-input markers are rebuilt for BACK from its own displayed FIRST only.
English draft/tags/slashes remain visible in the translator input.

This differs from RE1 examples and LB1 word boundaries, but shares the general
prompt-conditioning family with old S47/R7 sense hints. It is not established
that grammatical options outperform lexical hints. The two cards stay bounded;
additions based on individual failure sentences are outside this candidate.

The book is linked, not copied into the evidence bundle. See provenance.json.
Run test_adapter.py for source isolation and single-pass contract checks.
No live generation is authorized by this module.
