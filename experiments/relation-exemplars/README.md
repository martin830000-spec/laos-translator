# H RE1 / S EX1 — zero-call TEST candidates

Change ONLY the system context of frozen LA1/S1: add four direction-matched,
synthetic parallel examples. Keep model, thinking, LOW,2048, user input, output
contract and display extraction. Examples are invariant to the actual message.
The current message remains the sole user input; no conversation history or
original source is passed to BACK. A completed displayed FIRST supplies BACK.

H RE1 tests whether in-context contrasts of actor/recipient, condition/cause,
kinship direction and planned/completed events improve interpretation. It does
not propose source copying as a new fix: LA1 copying/units remain the controlled
baseline. There is no facts ledger then rewrite, source trigger, exception for
phone/bus/Friday, stronger JSON schema, lexical substitution or forced splitting.

S EX1 separates semantic and output hypotheses: relative-time/polarity examples
may stabilize meaning, and complete single-translation exemplars may reduce
public self-editing. This does not prove S1 role rules or missing reasoning cause
the observed failures. It adds no ban list, JSON constraint or thinking increase.
Raw English drafts, tags and meaning errors are preserved in both candidates.

Limitations: synthetic Lao exemplars are not native-reviewed; they can bias or
worsen translations and add input tokens. Existing copied output evidence is not
a new generation and cannot establish improvement. Actual quality, speed and
cost remain UNVERIFIED. P2 differences are accepted. No live HTTP or trigger.

Use haiku-re1/adapter.py or sonnet-ex1/adapter.py for engine-specific interfaces.
