3. C · 신규 3.1 FIRST + 독립 3.1 BACK

연구 프롬프트 계약 확인 중
전체 100건을 신규 실행하면 FIRST 100회 + BACK 100회로 최대 200회입니다. 자동 호출되지 않습니다.

API 과금: 파일 불러오기와 A/B 비교는 무료입니다. C는 사용자가 직접 버튼을 누르고 확인해야 호출합니다. BACK 요청에는 실제 C FIRST만 전달하고 원문·기존 A/B 결과는 전달하지 않습니다. 자동 재시도·숨은 유료 검사·자동 채점 없음. 실패도 시도 횟수에 포함합니다. API 직접 호출이 CORS/인증 때문에 차단되면 실패 기록을 보여주며 우회 프록시를 사용하지 않습니다.
