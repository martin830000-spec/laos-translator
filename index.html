🚀 1. 시작과 모드 선택

① 앱 열기첫 화면의 한-라오 번역기 시작을 누릅니다.
② 남편앱🇰🇷 한국을 선택하면 한국어를 라오어로 번역합니다.
③ 아내앱🇱🇦 ລາວ를 선택하면 라오어를 한국어로 번역합니다.
④ 모드 전환상단의 🇰🇷 / 🇱🇦 버튼으로 언제든 바꿀 수 있습니다.

✍️ 2. 텍스트 입력과 음성입력

🎙️ 음성입력 버튼은 번역 버튼 바로 아래에 있으며 번역 버튼과 같은 크기입니다.
한 번 누르면 듣기 시작하고, 말을 마친 뒤 다시 누르면 종료합니다. 생각하느라 중간에 쉬어도 자동 종료되지 않습니다.
🎙️ 앱 음성입력음성입력 버튼을 누르면 키보드를 강제로 띄우지 않고 입력창이 보이도록 화면을 맞춥니다. 인식된 글자가 들어온 뒤에도 입력창의 마지막 부분을 볼 수 있게 자동 조정합니다.
⌨️ 직접 입력·키보드 마이크직접 타이핑하거나 Samsung/Google/iPhone 키보드의 마이크를 그대로 사용할 수 있습니다. 남편앱에서는 앱 음성입력과 키보드 마이크의 정확도·속도를 직접 비교해도 됩니다.
✅ 인식 후 확인음성입력은 번역을 자동으로 시작하지 않습니다. 사람 이름, 날짜, 시간, 금액, 전화번호, 안/못/하지 마 같은 부정 표현을 확인한 뒤 번역 버튼을 누르세요.
🎙️ 남편·아내앱 음성인식 점수앱 음성입력 후 0~100점의 음성인식 점수가 표시됩니다. 실제 정답 발화와 대조한 정확도 백분율이 아니라 깨진 문자·다른 문자체계 혼입·불확실 부분 등을 확인하라는 참고값입니다.
PC에서는 Ctrl+Enter 단축키도 사용할 수 있습니다. 아내앱 화면에서는 공간을 아끼기 위해 단축키 안내 문구를 표시하지 않습니다.

🚀 3. 번역과 재번역

입력문을 확인한 뒤 파란색 번역 버튼을 누릅니다. 번역 중에는 같은 버튼으로 중지할 수 있습니다.

✅ 85~100눈에 띄는 형식 이상이 적은 범위입니다.
⚠️ 70~84감점 이유를 확인하는 것이 좋습니다.
⛔ 0~69문자·형식 이상 가능성이 높아 다시 확인하는 것이 좋습니다.
자동 재시도를 모두 거친 뒤에도 비치명적 품질검사에 실패하면 확인 가능한 실패 번역본을 표시합니다.
실패 번역본과 점수·감점 이유·재번역 버튼을 함께 보여주므로 사용자가 직접 확인하고 다시 시도할 수 있습니다. 의미반전·역할반전처럼 치명적 안전검사가 감지되면 먼저 안전 재번역을 시도합니다. 끝까지 복구되지 않아도 번역본은 숨기지 않고 낮은 점수·감점 사유와 함께 표시하므로 사용자가 직접 확인할 수 있습니다.
85점 미만이면 감점 이유 버튼 옆에 🔄 재번역이 나타납니다. 깨진 대체문자(�)가 발견되면 앱이 원래 입력문으로 자동 재번역을 딱 1회 시도합니다. 두 번째 결과에도 �가 남으면 결과는 표시하되 실수로 보내지 않도록 복사와 음성출력만 잠급니다. 점수는 번역 정확도를 보증하는 점수가 아니라 빠른 확인용 지표입니다.

🔍 4. 역번역으로 의미 확인

남편앱은 라오어 결과를 다시 한국어로, 아내앱은 한국어 결과를 다시 라오어로 확인할 수 있습니다. 문장이 원문과 똑같은지를 보는 것이 아니라 누가 무엇을 하는지, 긍정/부정, 날짜·시간·숫자·이동방향 같은 핵심 뜻이 유지됐는지 보는 기능입니다.

역번역도 번역 결과이므로 100% 판정기는 아닙니다. 중요한 약속이나 금액은 원문과 함께 확인하세요.

📋 5. 번역본 복사 방식

모드복사 방식
남편앱번역이 끝나면 역번역이 자동으로 준비됩니다. 번역본 복사를 누르면 첫 줄에 라오어 번역본, 바로 다음 줄에 도착한 한국어 역번역이 함께 복사됩니다. 복사 버튼이 별도의 역번역 요청을 새로 만들지는 않습니다. 빈 줄과 국가명/언어명 표시는 넣지 않습니다.
아내앱기본 복사 버튼은 한국어 번역본만 복사합니다. 역번역 결과는 별도의 의미확인 영역에서 확인하고 그 영역의 복사 버튼으로 따로 복사할 수 있습니다.
자동 역번역을 준비하지 못한 경우에는 입력 원문으로 대체하지 않고 라오어 번역본만 복사하고 안내합니다.

🔊 6. 음성출력

입력 영역 위쪽의 🔊 음성출력 토글로 자동 음성을 켜고 끌 수 있습니다. 켜져 있으면 번역 성공 후 상대 언어 음성을 들을 수 있고, 꺼져 있으면 자동 재생과 다시 듣기가 비활성화됩니다.

음성입력을 시작하면 재생 중이던 음성은 중지되어 휴대폰 스피커 소리가 다시 받아써지는 상황을 줄입니다.

🕘 7. 최근 번역·즐겨찾기

최근 번역은 남편앱·아내앱 각각 최대 50개까지 현재 기기에 저장됩니다. 화면에는 최근 10개를 간단히 표시하고, 관리자 진단에서는 저장된 실제 사용문장을 10/25/50개 선택해 현재 번역품질 회귀검사에 사용할 수 있습니다. 자주 쓰는 문장은 ⭐ 즐겨찾기로 남길 수 있습니다.

관리자 진단의 미니 용어사전에 자주 쓰는 음식·장소·이름 등을 등록하면, 해당 단어가 실제 원문에 등장할 때만 짧은 용어 힌트가 번역에 추가됩니다.

🧭 8. 자주 생기는 상황

상황확인 방법
음성입력 버튼을 눌렀는데 글자가 안 들어옴마이크 권한과 인터넷 연결을 확인하고, 말을 끝낸 뒤 같은 버튼을 다시 눌러 종료했는지 확인합니다.
음성입력 중 오래 쉬고 싶음그대로 쉬어도 됩니다. 자동으로 종료되지 않으며 직접 종료할 때까지 듣습니다.
번역품질 점수가 낮음번역문은 그대로 표시됩니다. 감점 이유를 보고 재번역 또는 역번역을 사용합니다. �가 남아 있으면 복사·음성출력이 잠기므로 재번역하세요.
남편앱 복사에 역번역이 안 붙음번역 직후 역번역이 자동으로 준비됩니다. 아직 처리 중이면 복사 버튼이 잠시 기다렸다가 도착한 역번역을 함께 복사합니다. 자동 역번역 자체가 실패한 경우에만 라오어 번역본만 복사되고 안내가 표시됩니다.
화면이 너무 아래로 밀림아내앱의 Ctrl+Enter 안내는 제거되어 있으며, 음성입력은 입력창을 보이게 자동 조정합니다.

🎙️ 2. ພິມ ແລະ ຮັບສຽງ

ປຸ່ມ 🎙️ ຮັບສຽງ ຢູ່ລຸ່ມປຸ່ມແປ ແລະມີຂະໜາດເທົ່າກັນ.
ກົດໜຶ່ງຄັ້ງເພື່ອເລີ່ມ ແລະກົດອີກຄັ້ງເພື່ອຢຸດ. ຢຸດເວົ້າຊົ່ວຄາວກໍບໍ່ປິດເອງ.
📱 ເມື່ອກົດຮັບສຽງແອັບຈະປັບໜ້າຈໍໃຫ້ເຫັນຊ່ອງພິມງ່າຍ ໂດຍບໍ່ບັງຄັບເປີດແປ້ນພິມ. ຫຼັງຂໍ້ຄວາມຈາກສຽງເຂົ້າມາ ຈະພະຍາຍາມໃຫ້ເຫັນສ່ວນທ້າຍຂອງຂໍ້ຄວາມ.
✅ ກວດກ່ອນແປການຮັບສຽງບໍ່ໄດ້ແປອັດຕະໂນມັດ. ກວດຊື່ຄົນ, ວັນທີ, ເວລາ, ເງິນ, ເບີໂທ ແລະຄຳປະຕິເສດ ແລ້ວຈຶ່ງກົດແປ.
🎙️ ຄະແນນຮັບສຽງຄະແນນ 0~100 ເປັນຄ່າຊ່ວຍກວດຕົວອັກສອນປົນ ຫຼືຈຸດທີ່ຄວນກວດ; ບໍ່ແມ່ນເປີເຊັນຄວາມຖືກຕ້ອງຈິງ.
ສາມາດໃຊ້ໄມໂຄຣໂຟນຂອງແປ້ນພິມໄດ້ຕາມປົກກະຕິ. ໃນໂໝດພັນລະຍາ ຂໍ້ຄວາມ Ctrl+Enter ຖືກຊ່ອນເພື່ອປະຢັດພື້ນທີ່ ແຕ່ໃນ PC ຍັງໃຊ້ປຸ່ມລັດໄດ້.

🛡️ 3. ຄະແນນຄຸນນະພາບ ແລະ ແປໃໝ່

✅ 85~100ບໍ່ພົບສັນຍານຜິດປົກກະຕິຊັດເຈນ.
⚠️ 70~84ຄວນເບິ່ງເຫດຜົນ.
⛔ 0~69ຄວນກວດ ຫຼືແປໃໝ່.
ຖ້າມີຂໍ້ຄວາມແປຈິງ ແອັບຈະຍັງສະແດງຜົນ ແມ່ນແຕ່ຄະແນນຕ່ຳ.
ຈະສະແດງຜົນແປ, ຄະແນນ ແລະເຫດຜົນພ້ອມກັນ. ຖ້າກວດພົບຄວາມໝາຍສູນເສຍ/ກັບດ້ານ ແອັບຈະລອງກູ້ຄວາມໝາຍກ່ອນ; ຖ້າຍັງບໍ່ສຳເລັດ ກໍບໍ່ຊ່ອນຜົນແປ ແຕ່ຈະສະແດງຄະແນນຕ່ຳ ແລະເຫດຜົນໃຫ້ກວດເອງ.
ຖ້າຕ່ຳກວ່າ 85 ຈະມີ 🔄 ແປໃໝ່. ຖ້າພົບຕົວອັກສອນເສຍ � ແອັບຈະລອງແປຈາກຕົ້ນສະບັບອີກ 1 ຄັ້ງເທົ່ານັ້ນ. ຖ້າຍັງມີ � ຜົນຈະຍັງສະແດງ ແຕ່ຈະປິດການຄັດລອກ ແລະສຽງ.

📋 5. ການຄັດລອກ

ໂໝດຜົວ: ຖ້າເປີດການຄັດລອກພ້ອມຜົນແປກັບ ແຖວທຳອິດແມ່ນຜົນພາສາລາວ ແລະ ແຖວຖັດໄປແມ່ນຜົນແປກັບພາສາເກົາຫຼີ ໂດຍບໍ່ມີແຖວວ່າງ ຫຼື ຊື່ປະເທດ/ພາສາ. ໂໝດພັນລະຍາ: ປຸ່ມຄັດລອກຫຼັກຈະຄັດລອກສະເພາະຜົນພາສາເກົາຫຼີ. ຜົນແປກັບຍັງກວດ ແລະ ຄັດລອກແຍກໄດ້ໃນສ່ວນກວດຄວາມໝາຍ.

🔊 6. ສຽງອ່ານ

ໃຊ້ປຸ່ມ 🔊 ດ້ານເທິງຂອງສ່ວນພິມເພື່ອເປີດ/ປິດສຽງ. ເມື່ອເລີ່ມຮັບສຽງ ສຽງທີ່ກຳລັງຫຼິ້ນຈະຖືກຢຸດ.
