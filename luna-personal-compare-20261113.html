GPT-6 Luna 실제 번역 비교 · TEST 전용

Gemini 3.8 SERVICE에 저장된 실제 원문을 같은 글자 그대로 Luna로 번역하는 실사용 비교 도구야. FIRST와 독립 BACK에 모두 GPT-6 Luna만 사용하고, BACK 입력에는 실제 FIRST 결과만 전달해. 자동 재시도·다른 제조사 전환·자동 AI 채점은 없어.

이 페이지에서는 시작 버튼을 직접 눌러야 유료 GPT API 호출이 발생해. N문장은 정상 완료 시 FIRST N회 + BACK N회 = 최대 2N회 생성 요청이 필요해. 실수로 여러 번 누르면 중복 요금이 발생할 수 있으니 결과를 저장하고 재실행 여부를 결정해. 원문·키·결과는 서버 DB에 자동 저장하지 않아. API 키는 현재 페이지의 메모리에만 있고 저장하지 않아.

실행 전
파일 내용은 이 브라우저에서 처리하고 GPT API에만 번역 원문을 보낸다. 별도의 서비스 서버, Firestore, Gemini API 또는 클라우드 백업으로 전송하지 않는다. 개인 대화이므로 출력 JSON/TXT는 공개 GitHub에 올리지 말 것.
타이밍은 해당 브라우저의 API 요청 시작~첫 텍스트 및 응답 완료 시간으로, 상대 기기 표시시간이나 이전 SERVICE 처리환경과 동일하다고 보장하지 않는다. 스트리밍은 FIRST 부분 출력 확인용이며 완료 전 문장을 실제 전송하지 말 것.
