GPT-6 Luna 단독 실사용 진단기 · TEST 전용

실사용 로그에서 한국어·라오어 원문만 추출해 GPT-6 Luna만 검사해. KF/KB는 N0 NAME + Fast, LF/LB는 BASE + Fast를 사용하고, 실제 FIRST 결과만 독립 BACK에 입력해. Gemini 등 다른 엔진은 호출하지 않아.

파일 불러오기·원문 선별·프롬프트 검사에는 API 요청 0회. 실행 버튼을 누르고 확인해야 Luna Fast 유료 생성 API를 호출해. N문장당 FIRST+BACK 최대 2N회이며 자동 재시도·fallback·유료 AI 채점은 없어. Fast 요금이 발생할 수 있고, 키·원문·결과는 GitHub나 DB에 저장하지 않아. 키는 이 페이지 메모리에만 유지하며 종료 전에 결과를 JSON/TXT로 저장해.

실행 전
파일은 현재 브라우저에서만 읽고, 실제 검사로 선택한 원문만 GPT API에 전송해. 별도 서버·Firestore·Gemini API·GitHub에 원문이나 결과를 업로드하지 않아. 개인정보가 들어있는 결과 JSON/TXT는 공개 저장소에 올리지 말 것.
타이밍은 해당 브라우저의 API 요청 시작~첫 텍스트 및 응답 완료 시간으로, 상대 기기 표시시간이나 이전 SERVICE 처리환경과 동일하다고 보장하지 않는다. 스트리밍은 FIRST 부분 출력 확인용이며 완료 전 문장을 실제 전송하지 말 것.
