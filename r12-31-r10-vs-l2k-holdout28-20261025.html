① Gemini API 키 (기존 키 재사용 · 로그인 불필요)

키는 이 브라우저의 localStorage에 자동 저장됩니다. 서버·GitHub·결과 파일에 저장하지 않지만, 같은 웹사이트의 스크립트 또는 PC 접근자가 읽을 수 있습니다. 테스트 전용 키만 입력하세요. 시크릿 모드·사이트 데이터 삭제 시 사라집니다. Lara 엔진을 실행하면 외부 jsDelivr SDK가 로드되며, 해당 코드는 입력 키에 접근할 수 있습니다.

Lara는 공급사의 인증 서명·토큰·SDK 절차를 사용합니다. 브라우저 CORS 또는 SDK 호환성이 검증되지 않은 상태입니다. 직접 호출이 막히면 자동으로 실패를 기록하며 임의의 프록시나 재호출을 하지 않습니다.

② 고정 비교 문장

한 줄에 K|한국어 원문 또는 L|라오어 원문을 입력하세요. 실제 부부 대화가 아닌 가상 예문만 기본 제공해요. K는 남편 정·역, L은 아내 정·역입니다.

한국어 10 · 라오어 10 · 고정 20문장

품질 비교 주의: 세 Gemini 모델은 동일한 중립 번역 프롬프트, temperature=0, thinkingLevel=LOW 및 정·역 각 1회로 비교합니다. SERVICE P168A R8의 SMART 규칙과 실사용 프롬프트는 재현하지 않으므로 이 검사의 3.8 수치가 SERVICE 자체의 품질·속도 기준선은 아닙니다.

역번역은 해당 엔진의 정번역 결과만 새 요청으로 다시 번역합니다. 원문과 별도의 '정답'을 주지 않으며, 역번역 일치율만으로 정번역 품질을 평가하지 않습니다.

Gemini 3종 검사: 2문장 시험 = 최대 12호출, 20문장 본검사 = 최대 120호출. 순서 교대 방식으로 같은 문장을 3모델에 순차 호출하며, 두 방향의 정번역·독립 역번역을 기록합니다. 1회 결과를 저장한 뒤 필요하면 2회 반복하세요. 새로고침하면 화면 결과가 사라집니다.

검사는 엔진별 정번역 1회 + 독립 역번역 최대 1회입니다. 실제 API 과금은 각 업체 계정에 발생할 수 있으며 1,000원 지출 한도를 보장하지 않습니다. 자동 재시도·품질 평가 추가 호출은 없습니다.
