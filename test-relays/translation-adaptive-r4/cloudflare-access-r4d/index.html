기본 번역·대조군 · 접어서 보관

일반 프롬프트 주입을 지원하지 않는 기존 API 비교군입니다.

R4B는 기존 엔진 종류 5개에 Lara 튜닝 + Gemini P168A 구성 참조를 더한 7개 비교군입니다. Gemini 중립도 LOW로 설정해 프롬프트 차이를 비교하므로, 기존 2026-10-14 중립(기본 thinking/temperature:0) 실험과 설정이 다릅니다. P168A 필드는 인증된 TEST Worker의 동일 출처 prompt-config.json을 SHA 고정 검증해 로드합니다. 이 경로는 SMART OFF/LOW 구성참조이고 실제 SERVICE의 전체 실행 경로·SMART 조립·Relay와 동등하지 않습니다. Google NMT/TLLM은 기본형, Azure는 대조군입니다.

Adaptive는 별도 R4 TEST 서버와 Cloudflare Access 인증 중계로 사용합니다. 브라우저에 토큰을 입력하지 않습니다. 인증 관문·일일 중앙 제한이 설정되기 전에는 실행하지 마세요. 검수한 양방향 예문 1~5쌍이 필요하며 예문은 자동 저장하지 않습니다.

TXT 파일을 브라우저에서만 읽고, 키 입력칸을 자동으로 채웁니다.
미적용 · Gemini 중립 / Lara 기존 지시문 사용

통합 TXT V2는 Gemini 4경로 프롬프트, Lara 4경로 지시문, Adaptive 양방향 예문을 한 파일에 포함합니다. NMT·기본 Translation LLM·Azure는 프롬프트 미지원 대조군으로 실행합니다. V1도 호환됩니다. TXT는 브라우저에서만 읽고 새로고침하면 해제되며, 검사 기록에는 후보명·SHA-256만 남습니다.

키 파일 자체는 서버로 전송하지 않습니다. 불러온 키는 기존 설정처럼 이 브라우저의 localStorage에 저장되며, 각 번역 엔진 호출 시 해당 제공자에게 전송됩니다. 실제 키를 적은 TXT 파일은 외부에 공유하지 마세요.

API 키·모델 상세 설정 펼치기

Lara는 공급사의 인증 서명·토큰·SDK 절차를 사용합니다. 브라우저 CORS 또는 SDK 호환성이 검증되지 않은 상태입니다. 직접 호출이 막히면 자동으로 실패를 기록하며 임의의 프록시나 재호출을 하지 않습니다.

품질 비교 주의: 이 페이지의 Gemini는 중립 단순 프롬프트로 호출하므로 기존 SERVICE P168A의 정확한 실행 경로·SMART·LOW 설정과 동등한 기준선이 아닙니다. 엔진별 결과 참고용이며 SERVICE 대비 우월성 판정에 사용하지 마세요.

역번역은 해당 엔진의 정번역 결과만 새 요청으로 다시 번역합니다. 원문과 별도의 '정답'을 주지 않으며, 역번역 일치율만으로 정번역 품질을 평가하지 않습니다.

권장 순서: R4B 첫 실행은 신규 8문장 × 1회가 권장됩니다. 기존 20문장은 오류 분석용으로 보존합니다. 7개 비교군 전체 실행 시 최대 112번 API를 호출합니다. Adaptive는 미포함이며, 비용이 발생할 수 있습니다. 추가 자동 재시도는 없습니다.

검사는 엔진별 정번역 1회 + 독립 역번역 최대 1회입니다. 실제 API 과금은 각 업체 계정에 발생할 수 있으며 1,000원 지출 한도를 보장하지 않습니다. 자동 재시도·품질 평가 추가 호출은 없습니다.
